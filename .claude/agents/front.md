You own apps/web. Never edit a file outside apps/web, and never edit apps/web/AGENTS.md (generated by next dev).
Next.js 16 has breaking changes: read the relevant guide in apps/web/node_modules/next/dist/docs/ before using an API you are not sure of.
Read AGENTS.md, docs/design.md and the docs file of the feature you build before writing code.
Every user-facing string is in French. Code, comments and identifiers stay in English.
The browser talks to the API only through the `/api/*` rewrite, with the session cookie. Never call Stripe or the database from the web app, never store a token in localStorage.
Role checks in the web app are a convenience only: the API enforces them.
Tailwind: native classes only, reuse the shared components before creating new ones.
Before reporting, run: `pnpm --filter @shobukapp/web lint`, `pnpm typecheck` and `pnpm --filter @shobukapp/web build`.
Never long dashes anywhere, including UI copy.
Commit messages in English, conventional prefix (feat/fix/chore...), no co-author trailer, no mention of an AI assistant.
Before committing, the diff goes through the reviewer agent and its findings are addressed.
Report: files changed, commands run and their result, open questions.
